# XP-Pen Deco 03 Linux Keyboard Layout Issue

## Summary

The XP-Pen Linux driver has incorrect keyboard handling when using non-US keyboard layouts.

Changing the keyboard layout from German (DE) or French (FR) to English (US) fixes the problem.

## Hardware

- XP-Pen Deco 03

## Driver

- XPPenLinux-3.4.9-240607

## Tested driver packages

The same driver version was tested using different package formats provided by XP-Pen:
- XPPenLinux3.4.9-240607.tar.gz on Arch Linux
- XPPenLinux3.4.9-240607.deb on Ubuntu
- XPPenLinux-3.4.9-240607.rpm on Fedora

## Tested systems

The issue was reproduced on:

- Ubuntu 24.04
- Arch Linux 26.07.01
- Fedora 44

Display systems:

- Wayland
- X11

Desktop environments tested on Fedora:

- GNOME
- XFCE

## Problem
Observed behavior on other layouts:
- Tablet express keys trigger incorrect shortcuts.
- Keyboard input generated by the driver can produce wrong characters.
- Example (German layout):
  - Ctrl+Z is interpreted as Ctrl+Y.
- The Deco 03 wheel functions incorrectly in applications like Krita:
  - Instead of changing brush size, it performs zoom actions.

## Investigation

The XP-Pen driver configuration files were inspected and appeared to be configured correctly. Further investigation showed that the issue depends on the active keyboard layout. It appears to handle keyboard events in a way that does not correctly respect non-US keyboard layouts.

The result is that the driver sends key inputs for an US keyboard to the virtual keyboard. This causes incorrect shortcuts and characters on other keyboard layouts.

## Relation to XP-Pen documentation

The XP-Pen Deco 03 manual states that the express keys are designed to work with US English keyboards and that other keyboard languages may not function correctly.

While the documentation specifically mentions express keys, testing shows that the problem also affects other keyboard events generated by the driver. This includes the wheel outputs.

## Solution / Workaround

Switch the system keyboard layout to English (US). 
- You can use a shortcut to change between the different keyboard layouts

After switching:

- Ctrl+Z works correctly
- Tablet shortcuts work correctly
- The Deco 03 wheel executes the right commands

## Possible affected devices

The investigated driver version contains shared configuration entries for multiple XP-Pen Deco models.

Because keyboard event handling appears to be implemented in shared driver code, the issue may potentially affect other models using the same driver framework.

Confirmed device tested:
- Deco 03

Other models found in driver files:
- Deco01
- Deco01V2
- DecoProSW
- DecoProS
- DecoProM
- DecoProMW
- DecoMini4
- DecoMini7
- DecoMW

## Conclusion

The issue is reproducible across multiple Linux distributions, desktop environments, and display systems.

The problem does not appear to be related to:

- Linux distribution
- Wayland/X11
- Desktop environment
- Driver package format

It appears to be a keyboard layout compatibility issue in the XP-Pen Linux driver for multiple devices.
